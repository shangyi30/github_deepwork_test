# github_deepwork

一段不被打断的深度工作计时器。写下这一段要完成的事，选 25 / 50 / 90 分钟（或自定义），开始后只做这一件。

会话记录保存在浏览器本地，不需要登录，也没有后端。

## 本地运行

```bash
npm install
npm run dev
```

默认在 [http://127.0.0.1:43127](http://127.0.0.1:43127) 打开。

```bash
npm run build
npm start
```

## 能做什么

- 选择预设时长，或输入 5–240 分钟
- 开始、暂停、提前完成、放弃并记录
- 查看今天已完成的块和合计时间
- 空状态、读取中、本地存储失败都会有明确提示
